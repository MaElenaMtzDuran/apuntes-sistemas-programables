# 1.1 Características generales

### 1.1.1 Introducción

Todos los días necesitamos interactuar con dispositivos electrónicos, cada uno de nosotros tiene teléfono, televisión, refrigerador, lavadora, cámara, entro otros sistemas electrónicos, son una parte importante en nuestro trabajo como personas, facilitando las actividades en la vida diaria y proporcionando entretenimiento.

Un sistema electrónico se describe como un conjunto de elementos electrónicos que interactúan para recibir información del entorno, procesarla y generar una respuesta al usuario [\[1\]](../chapters/capitulo7/), la entrada al sistema se realiza mediante los sensores, los cuales captan el entorno tal como lo hace un ser humano: olfato, gusto, vista, tacto y oído. Una vez identificada la información de entrada, de forma digital (0's y 1's) o analógica (manera continúa), es procesada por un conjunto de elementos o por un **controlador**, el cual puede interactuar con otros sistemas para realizar tareas más complejas, este proceso de comunicación se realiza a través de protocolos predefinidos. Una vez procesada la información se genera la salida correspondiente, que puede ser a través de una visualización (Led, matrices de Leds, display de siete segmentos o pantallas de cristal líquido) o mediante un actuador, dispositivo electrónico o electromecánico, capaz de modificar el entorno (motores, electroválvulas, relevadores). El concepto de controlador no ha cambiado con el tiempo, pero su implementación física a evolucionado con los los avances tecnológicos [\[1\]](../chapters/capitulo7/). Para los  primeros sistemas electrónicos, los controladores se construyeron utilizando circuitos analógicos, las decisiones se tomaban con diferentes configuraciones de transistores o amplificadores operacionales. Para los setentas se empleaba lógica discreta con circuitos digitales de baja o mediana escala de integración.&#x20;
