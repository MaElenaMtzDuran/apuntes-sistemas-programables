# 1.1 Características generales

### 1.1.1 Introducción

Todos los días necesitamos interactuar con dispositivos electrónicos, cada uno de nosotros tiene teléfono, televisión, refrigerador, lavadora, cámara, entro otros sistemas electrónicos, son una parte importante en nuestro trabajo como personas, facilitando las actividades en la vida diaria y proporcionando entretenimiento.

Un sistema electrónico se describe como un conjunto de elementos electrónicos que interactúan para recibir información del entorno, procesarla y generar una respuesta al usuario [\[1\]](../chapters/capitulo7/), la entrada al sistema se realiza mediante los sensores, los cuales captan el entorno tal como lo hace un ser humano: olfato, gusto, vista, tacto y oído. Una vez identificada la información de entrada, de forma digital (0's y 1's) o analógica (manera continúa), es procesada por un conjunto de elementos o por un **controlador**, el cual puede interactuar con otros sistemas para realizar tareas más complejas, este proceso de comunicación se realiza a través de protocolos predefinidos. Una vez procesada la información se genera la salida correspondiente, que puede ser a través de una visualización (Led, matrices de Leds, display de siete segmentos o pantallas de cristal líquido) o mediante un actuador, dispositivo electrónico o electromecánico, capaz de modificar el entorno (motores, electroválvulas, relevadores). El concepto de controlador no ha cambiado con el tiempo, pero su implementación física a evolucionado con los avances tecnológicos [\[1\]](../chapters/capitulo7/). Para los  primeros sistemas electrónicos, los controladores se construyeron utilizando circuitos analógicos, las decisiones se tomaban con diferentes configuraciones de transistores o amplificadores operacionales.&#x20;

<figure><img src="../.gitbook/assets/Imagen2 Controlremoto.jpg" alt=""><figcaption><p>Figura 1.2 Control remoto en los años 50's (Imagen tomada de <a href="https://www.bbc.com/mundo/vert-fut-45595529">https://www.bbc.com/mundo/vert-fut-45595529</a>)</p></figcaption></figure>



Para los setentas se empleaba lógica discreta con circuitos digitales de baja o mediana escala de integración.&#x20;

En 1971 surge el **primer microprocesador (4004 de Intel),**  lo cual permitió el desarrollo de las tarjetas de control con un microprocesador (procesador, mmoria, entrada/salida, etc.). A estas tarjetas también se les conoce como **Computadoras en una Sola Tarjeta (SBC, single board computer).** [\[1\]](../chapters/capitulo7/).

En la actualidad todos estos elementos se encuentran en un circuito integrado único y a este se le refiere como Unidad Micro Controladora (MCU, Micro Controller Unit) o simplemente como Microcontrolador.

<figure><img src="../.gitbook/assets/Imagen3 infografía microcontroladores.png" alt=""><figcaption><p>Figura 1.3 Evolución de los microcontroladores (Imagen generada con Notebook)</p></figcaption></figure>

Un **Microcontrolador** es un circuito programable con una escala de integración muy grande (VLSI, _very large scale integration_) que internamente contiene una Unidad Central de Procesamiento (CPU, _Central Processing Unit_), memoria para código, memoria para datos, temporizadores, fuentes de interrupción y otros recursos necesarios para el desarrollo de aplicaciones, por lo general con un propósito específico.&#x20;

Para esto, el microcontrolador utiliza muy pocos componentes asociados. Un sistema con microcontrolador debe disponer de una memoria donde se almacena el programa que gobierna el funcionamiento del mismo, que una vez programado y configurado, sólo sirve para realizar la tarea asignada \[2].&#x20;

\
A pesar de que un MCU incluye los elementos necesarios para ser considerado como una computadora en un circuito integrado, frecuentemente no es tratado como tal porque su uso típico consiste en el desempeño de funciones de “control” interactuando con el “mundo real” para monitorear condiciones (a través de sensores) y en respuesta a ello, encender o apagar dispositivos (por medio de actuadores).
